# 감정 단어 사전

> 이 문서는 ATLAS 전체에서 사용되는 감정 용어의 정의.
> 에이전트가 대본/분석/검색 시 이 정의를 기준으로 판단.
> 출처 표기된 것은 해당 문헌 기준, 없는 것은 운영 정의.

## 기본 감정 6가지 (에크만)
| 감정 | 영어 | 정의 | 아동 표현 예시 |
|------|------|------|-------------|
| 기쁨 | joy | 욕구 충족, 긍정적 기대 실현 | 웃음, 점프, "좋아!" |
| 슬픔 | sadness | 상실, 분리, 기대 좌절 | 울음, 위축, 조용해짐 |
| 분노 | anger | 목표 차단, 불공정 인식 | 소리지름, 던지기, 발 구르기 |
| 공포 | fear | 위협 인식, 안전 불안 | 숨기, 매달리기, "무서워" |
| 놀람 | surprise | 예상 밖 사건 | 눈 크게 뜸, 멈춤 |
| 혐오 | disgust | 거부 반응 | 밀어내기, "싫어" |

## 복합 감정 (아동에게 자주 나타나는)
| 감정 | 구성 | 정의 |
|------|------|------|
| 불안 | 공포 + 예측 | 미래 위협에 대한 지속적 걱정 |
| 질투 | 분노 + 슬픔 | 관심/자원이 타인에게 가는 것에 대한 반응 |
| 수치심 | 슬픔 + 공포 | 자기 전체가 잘못되었다는 느낌 |
| 죄책감 | 슬픔 + 분노(자기향) | 특정 행동이 잘못되었다는 느낌 |
| 외로움 | 슬픔 + 결핍 | 연결 부재에 대한 고통 |
| 좌절 | 분노 + 무력감 | 노력해도 안 될 때 |

## empathy-collector 6태그 (ch2 댓글 분류용)
| 태그 | 정의 | 매칭 감정 |
|------|------|----------|
| 공감 | 시청자가 자신의 경험과 연결 | 슬픔, 외로움 |
| 감사 | 채널/영상에 대한 고마움 | 기쁨 |
| 반성 | 자기 양육을 돌아봄 | 죄책감, 수치심 |
| 질문 | 궁금한 것, 도움 요청 | (정보 요구) |
| 응원 | Genmon/다른 부모에게 격려 | 기쁨, 연대 |
| 고백 | 자신의 힘든 경험 공유 | 슬픔, 외로움, 좌절 |

## 동의어 정리
| 우리 용어 | 동의어 | 비고 |
|----------|--------|------|
| 감정조절 | 정서조절, emotion regulation | ATLAS 전체에서 통일 |
| 감정코칭 | emotion coaching | 가트맨 5단계 기준 |
| 감정폭발 | meltdown, tantrum | tantrum=의도적, meltdown=비자발적 구분 |
| 공감 | empathy | 정서적 공감 + 인지적 공감 포함 |
| 애착 | attachment | 보울비 기준, 4유형 |
