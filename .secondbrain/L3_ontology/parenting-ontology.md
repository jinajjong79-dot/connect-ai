# 육아 온톨로지 — 용어 관계 맵

> 핵심 개념들 사이의 관계를 정의.
> 에이전트가 "이 개념이 저 개념과 어떻게 연결되는지" 판단할 때 사용.

## 핵심 개념 계층

```
양육 (Parenting)
├── 양육 태도
│   ├── 권위적 (authoritative) — 온정 + 통제 균형 ✅ 권장
│   ├── 권위주의적 (authoritarian) — 통제 위주
│   ├── 허용적 (permissive) — 온정 위주, 통제 부족
│   └── 방임적 (neglectful) — 둘 다 부족
│
├── 감정코칭 (Gottman) — [[EC-001-emotion-coaching]]
│   ├── 1단계: 감정 인식 → [[emotion-vocabulary]]
│   ├── 2단계: 연결의 기회로 보기
│   ├── 3단계: 공감적 경청
│   ├── 4단계: 감정에 이름 붙이기 → [[emotion-vocabulary]]
│   └── 5단계: 한계 설정 + 문제해결
│
├── 애착 이론 (Bowlby/Ainsworth)
│   ├── 안정 애착 (secure) ✅
│   ├── 불안-양가 애착 (anxious-ambivalent)
│   ├── 회피 애착 (avoidant)
│   └── 혼란 애착 (disorganized)
│   관련: [[AT-133-attachment-brain-morphology]]
│
└── 발달 지원
    ├── K-DST 선별 → [[development-domains]]
    ├── 누리과정 → 놀이 중심
    └── 조기 개입 — "빠를수록 효과적" 원칙

아동 발달 (Child Development)
├── 신체 발달 → 대근육 + 소근육
├── 인지 발달 → 피아제 단계, 실행기능
├── 언어 발달 → 이해 + 표현
├── 정서 발달 → 감정 인식 → 감정 조절 → 감정 표현
│   관련: [[emotional_development]]
├── 사회성 발달 → 또래관계, 공감, 이타행동
│   관련: [[social_development]]
└── 도덕 발달 → 규칙 이해, 공정성

부모 정신건강 (Parent Mental Health)
├── 양육 스트레스
├── 양육 번아웃
├── 부모 자기돌봄
├── 사별 애도 → [[grief_support]]
│   ├── 정상 애도
│   ├── 복합 애도 (complicated grief)
│   └── 아동 애도 — 형제 사별 포함
│       관련: [[sibling_loss]]
└── ch2 핵심: "아이를 돌보려면 먼저 나를 돌봐야 한다"
```

## ch2 콘텐츠 위치 맵
```
EP01 감정폭발 → 감정코칭 1단계(감정 인식) + 정서발달
EP02 말습관 → 부모 커뮤니케이션 + 양육 태도
EP03 감정표현 → 감정코칭 4단계(이름 붙이기) + 언어발달
EP04 부모의 감정 → 부모 정신건강 + 양육 스트레스
KEY 감정코칭 한달 → 감정코칭 전체 + 실천 기록
```

## 용어 관계 유형
- A ⊂ B: A는 B에 포함됨 (감정코칭 ⊂ 양육)
- A ↔ B: 상호 영향 (애착 ↔ 감정조절)
- A → B: A가 B에 선행 (감정 인식 → 감정 표현)
- A ≈ B: 유사 개념 (감정조절 ≈ 정서조절)
