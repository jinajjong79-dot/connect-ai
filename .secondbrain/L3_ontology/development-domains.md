# 발달 영역 정의

> K-DST 및 누리과정 기반. 에이전트가 발달 관련 판단 시 이 정의 기준.
> ⚠️ 이 문서는 "진단"이 아닌 "이해"를 위한 것. 에이전트는 절대 진단하지 않음.

## K-DST 6개 영역

### 1. 대근육운동 (Gross Motor)
- 정의: 큰 근육을 사용하는 신체 움직임
- 예: 걷기, 뛰기, 계단 오르기, 공 던지기
- 관련 ATLAS: [[normal_development]]

### 2. 소근육운동 (Fine Motor)
- 정의: 작은 근육을 사용하는 정밀한 움직임
- 예: 그리기, 가위질, 블록 쌓기, 젓가락 사용
- 관련 ATLAS: [[normal_development]]

### 3. 인지 (Cognition)
- 정의: 사고, 문제해결, 개념 이해 능력
- 예: 색깔/모양 구분, 수 개념, 분류, 패턴
- 관련 ATLAS: [[normal_development]], [[EF-220-executive-function]]

### 4. 언어 (Language)
- 정의: 이해 언어 + 표현 언어
- 예: 어휘력, 문장 구성, 지시 이해, 질문하기
- 관련 ATLAS: [[language_development]]

### 5. 사회성 (Social)
- 정의: 타인과의 관계 형성 및 유지 능력
- 예: 차례 지키기, 나누기, 또래 놀이, 규칙 이해
- 관련 ATLAS: [[social_development]]

### 6. 자조 (Self-Help)
- 정의: 스스로 일상생활을 수행하는 능력
- 예: 옷 입기, 식사, 세수, 화장실 사용
- 관련 ATLAS: [[normal_development]]

## 연령별 핵심 (세현이 참고, 만 5세 기준)
| 영역 | 만 5세 기대 수준 |
|------|---------------|
| 대근육 | 한 발로 5초 서기, 줄넘기 시도 |
| 소근육 | 세모/네모 그리기, 가위로 곡선 자르기 |
| 인지 | 10까지 세기, 간단한 덧셈뺄셈 개념 |
| 언어 | 5~6단어 문장, 과거형 사용, 이유 설명 |
| 사회성 | 규칙 있는 게임, 양보/타협 시도 |
| 자조 | 혼자 옷 입기, 스스로 세수 |

## 절단점 해석 주의
- "빠름/또래수준/추적관찰/심화평가" 4단계
- 추적관찰 = "문제"가 아니라 "다시 보자"
- 에이전트는 "지연"이라는 단어 사용 금지 → "추적관찰 영역" 사용
