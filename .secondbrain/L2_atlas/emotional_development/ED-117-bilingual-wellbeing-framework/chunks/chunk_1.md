=== 핵심 프레임워크 ===

본 논문은 부모의 언어 인식·능숙도 → 아동 이중언어 경험 → 사회정서 웰빙으로 이어지는 4단계 개념 프레임워크를 제시한다.

4단계 구조:
1단계: 부모의 언어 인식 및 능숙도 (Parental Language Perception & Proficiency)
2단계: 부모의 언어 사용 패턴 (Parental Language Use)
3단계: 아동의 이중언어 경험 (Child Bilingual Experience)
4단계: 아동의 사회정서 웰빙 (Child Social-Emotional Wellbeing)

핵심 주장: "조화로운 이중언어(Harmonious Bilingual Experience)" 경험이 아동의 사회정서 발달을 촉진한다.

=== 이중언어와 사회정서 발달 ===

## 아동의 이중언어 사용과 친사회적 행동

싱가포르 유아 805명 연구:
- "두 언어를 사용한 개월 수"가 친사회적 기술과 유의미하게 정적 상관
- 이중언어 아동은 사회적 맥락에 따른 언어 분화 능력이 더 강함
- 언어 전환 능력 = 관점 전환 능력으로 연결 → 공감 발달 촉진

이중언어의 사회인지 이점:
- False Belief Task(마음이론 과제): 이중언어 아동이 단일언어 아동보다 빠른 발달
- 실행 기능(Executive Function): 주의 집중, 억제 통제 능력 향상
- 감정 어휘: 두 언어에서 감정 표현 → 감정 이해의 폭 확장

## 가정 문해 활동과 감정 발달

공유 독서(Shared Book Reading)의 감정 발달 효과:
- 아동 도서는 감정·사회 참조가 풍부 (분노, 슬픔, 기쁨, 공감 장면)
- 도서를 통한 감정 이름 짓기 → 감정 조절 능력 향상
- 사회 규범·도덕적 행동 노출 → 친사회적 행동 기반 형성

이중언어 환경에서의 독서:
- 가정 언어(L1) 도서 → 문화적 정체성 + 조부모 연결
- 학교 언어(L2) 도서 → 또래 관계 + 사회 적응
- 두 언어 도서 모두 노출 = 최적 조합

## 이중언어 능숙도와 관계 웰빙

모국어(Heritage Language) 유지의 중요성:
- 부모와의 소통 깊이: 감정·가치관 전달은 모국어에서 더 자연스러움
- 조부모 관계: 모국어 유지 → 세대 간 유대 강화
- 문화적 정체성: 양쪽 문화 정체성 형성 → 심리적 안정감

또래 수용과 학교 적응:
- 학교 언어(L2) 능숙도 → 또래 수용 → 소속감
- 이중언어 유창성 = 두 집단에 모두 수용될 수 있는 자원

=== 부모 요인: 언어 인식과 사용 ===

## 부모의 언어 태도

부모의 이중언어 태도 유형:
1. 긍정적 태도: "두 언어 모두 중요하다" → 아동에게 양쪽 언어 모두 노출
2. 다수 언어 편향: "학교 언어(L2)가 더 중요" → 모국어 투입 감소
3. 모국어 강조: "집에서는 반드시 L1만" → L2 발달 지연 위험

최적 태도: 두 언어 모두 가치 있다고 인식 → 균형 있는 언어 입력 제공

## 부모의 언어 능숙도와 입력 질

부모가 L2(학교 언어)에 능숙하지 않을 때:
- 학교에서 있었던 일을 함께 처리하기 어려움
- 감정 코칭이 모국어로만 가능 → 학교 맥락의 감정은 다루기 어려움

해결 방안:
- 강점 활용: 부모는 L1에서 더 풍부한 감정 어휘 사용 가능
- L1 독서 확대: 모국어 도서를 통한 감정 대화
- 학교 소통 지원: 이중언어 교사/통역 활용

=== 다문화·이중언어 가정 양육 시사점 ===

한국 다문화 가정 맥락 적용:

1. "모국어 = 약점" 인식 탈피
   - 어머니의 모국어(베트남어, 중국어, 필리핀어 등)는 아이의 자산
   - 모국어 유지 → 감정적 유대 + 다중 문화 정체성

2. 이중언어 감정 코칭
   - 아이의 감정을 두 언어로 이름 짓기: "화났구나(Korean) / tức giận(Vietnamese)"
   - 두 언어에서의 감정 어휘가 풍부할수록 감정 조절 능력 향상

3. 가정 독서 언어 선택
   - 모국어 도서: 취침 전 정서적 유대 강화
   - 한국어 도서: 낮 시간대 학교 연계 독서
   - 비율: 자녀 연령과 환경에 따라 유연하게

4. 친사회적 기술 발달
   - 이중언어 아동: 또래 갈등 시 관점 전환 능력 우위
   - 두 문화 이해 → 다양한 배경 친구와 관계 형성 용이
