## 시기별 아이돌보기 — 성장발달 특징

**출처**: 대한병원간호사회 | 간호사가 알려주는 홈케어

---

### 신생아
**발달 특징**
- 배꼽은 생후 2주일 전후에 떨어짐
- 출생 직후 3~4일간 일시적 체중 감소 후 7~8일에 회복
- 생후 한 달에 약 1kg 체중 증가
- 하루 20시간 이상 수면
- 생후 한 달 무렵 목 가누기 시작, 빛과 소리에 반응

**양육 지침**
- 울음은 의사소통 수단이므로 안아주고 쓰다듬어주기
- 기저귀와 의류를 자주 세탁
- 병에 대한 저항력 부족으로 외부인 출입 제한
- 황달 증상 시 일광욕 및 병원 방문

### 1~2개월
**발달 특징**
- 팔, 다리 운동 활발화
- 시각과 청각 발달 시작
- 혼자 웃기 시작, 깨어있는 시간 증가

**양육 지침**
- 부모가 상냥하게 소리 내어 응대하고 모빌 보여주기
- 생후 1개월에 소아과 건강검진
- 신선한 공기와 햇볕 노출
- 영아산통 시 자주 달래기 (생후 1개월부터 3~4개월까지)

### 2~3개월
**발달 특징**
- 시력 발달로 움직이는 물체 추적 관찰
- 땀구멍 발달, 습진 위험 증가
- 밤 수면 증가, 낮 활동 시간 증가
- 목 가누기, 옹알이 시작

**양육 지침**
- 상냥한 응대와 모빌 보여주기
- 손톱 관리
- 시원한 환경 제공, 매일 목욕

### 3~4개월
**발달 특징**
- 체중이 출생 시의 2배로 증가
- 목을 가누게 됨
- 침 흘리기 시작
- 주위 사람과의 접촉 선호, 웃음과 소리 발달
- 손에 장난감을 쥐고 손을 입으로 가져가 빨기

### 4~5개월
**발달 특징**
- 목을 자유롭게 움직임
- 뒤를 받쳐주면 잠시 앉음
- 물건을 주면 손을 내밀어 붙잡음
- 음식에 관심 표현

### 5~6개월
**발달 특징**
- 운동기능과 정신 발육 활발화
- 스스로 뒤집기 가능
- 좋고 싫음을 분명하게 표현

**양육 지침**
- 위험한 물건을 아기 손이 닿을 수 없는 곳에 배치
- 이유식 시작 고려

### 6~7개월
**발달 특징**
- 이가 나기 시작
- 몸을 뒤치기 시작
- 호기심 왕성, 배밀이 시작

**양육 지침**
- 치아발육기 준비
- 홍역 유행 시 생후 6개월부터 홍역 단독 백신 접종

### 7~8개월
**발달 특징**
- 혼자 앉음
- '마마', '바바' 자음 소리 발성
- 낯선 사람에게 부끄러움 (낯가림)
- 양손을 자유롭게 사용, 무릎으로 기기 시작

**양육 지침**
- 젖니 관리 시작 (거즈로 청소)
- 분리불안에 대비한 애착관계 형성

### 8~9개월
**발달 특징**
- 가족 인식, 자신의 이름에 반응
- 기어다니기 시작
- 혼자 앉기 가능, 잡아주면 일어남
- 도움받아 컵으로 마심
- 한 단어 이상 말하고 '짝짝꿍' 따라하기

### 10~11개월
**발달 특징**
- 붙들고 걷기
- 타인의 말을 이해
- 대천문이 닫히기 시작
- 손 사용 능숙화

### 11~12개월
**발달 특징**
- 발육이 좋으면 걷기 시작
- 컵으로 마시기
- '엄마', '아빠' 정도의 단어 사용
- 자기주장 강화, 또래 친구에 대한 관심

**양육 지침**
- 식사 하루 세 번 (아침, 점심, 저녁)
- 간식 하루 1~2회

### 12~15개월
**발달 특징**
- 혼자 걷기 가능
- 컵을 손으로 잡고 물 마시기
- 수저 사용 가능

### 15~18개월
**발달 특징**
- 신발과 옷 벗기 가능
- 공 가지고 놀이, 간단한 지시 따르기

### 18~24개월
**발달 특징**
- 뛰기
- 많은 단어 사용
- 수저로 스스로 먹기

**양육 지침**
- 배변 훈련 시작 (실패 시 훈책하지 않기, 성공 시 칭찬)
- 먹고, 입고, 씻고, 자는 등의 기본 생활습관 교육

### 2~3세
**발달 특징**
- 반항 시기
- 호기심과 상상력 풍부 (공상과 현실 구별 못함)
- 부모 흉내 내기

### 3~4세
**발달 특징**
- 탐색적이고 모험적인 놀이 선호
- 독립심 발달, 사회의 일원으로 행동 욕구
- 친구와의 역할 학습
- 성에 대한 호기심

### 4~5세
**발달 특징**
- 일의 결과 추리 가능

### 5~6세
**발달 특징**
- 무서움을 느낌
- 충동적이고 변덕스러움
- 대소변 조절 가능
- 10 이하의 간단한 숫자 세기

### 6~12세
**발달 특징**
- 유치가 영구치로 교체
- 운동놀이 학습
- 지적 추리기능 발달
- 사회화 학습, 또래집단 연대감 형성

## 연령별 이정표 요약

| 연령 | 핵심 발달 |
|------|---------|
| 신생아 | 울음 의사소통, 빛·소리 반응, 1kg/월 체중 증가 |
| 1~3개월 | 목 가누기, 옹알이 시작, 시청각 발달 |
| 4~6개월 | 뒤집기, 손 사용, 이유식 시작, 음식 관심 |
| 6~9개월 | 첫 이, 배밀이, 이름 반응, 낯가림, 첫 단어 |
| 9~12개월 | 기기, 잡고 서기, 짝짜꿍 따라하기 |
| 12~18개월 | 혼자 걷기, 수저 사용, 단어 증가 |
| 18~24개월 | 뛰기, 배변훈련 시작, 2단어 문장 |
| 2~3세 | 반항기, 상상놀이, 부모 흉내 |
| 3~6세 | 독립심, 또래관계, 규칙 이해, 숫자 세기 |
