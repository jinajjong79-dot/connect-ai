# FR-286 Source

Title: Family Meals and Child Academic and Behavioral Outcomes
Authors: Daniel P. Miller, Jane Waldfogel, Wen-Jui Han
Journal: Child Development
Year: 2012
Volume: 83(6):2104-2120
PMC ID: PMC3498594
PMID: 22880815

## ⚠️ 데이터 정확성 주의 — 핵심 발견 역전
- 사용자 기재 N=24,000+ → 실제 N=21,400
- 사용자 기재 "가족 식사↑→학업↑ 문제행동↓" → 실제 인과 모델에서 NULL 결과
- 풀드 모델에서는 연관 보임 → 그러나 아동 고정효과 모델(교란 통제)에서 효과 사라짐
- 이 논문의 핵심 기여: "기존 연구의 가족 식사 효과 = 혼재 편향"

## Methods
Sample: N=21,400 유치원생 (ECLS-K 코호트), 42,820~85,640 아동-학년 관찰
Age: 5-15세 (유치원~8학년, 1999-2007)
Design: 종단 패널, 5회 데이터 웨이브
분석 방법:
  1. 풀드 회귀 모델 (pooled)
  2. 지연 종속변수 모델 (LDV)
  3. 아동 고정효과 모델 (child fixed effects) ← 주요 분석

변수: 가족 아침/저녁 식사 빈도(0-7일/주), 읽기·수학·과학 표준점수, 내재화·외현화 행동(1-4척도)

## Key Results
풀드 모델:
- 아침 식사 1회 추가 → 학업점수 약 0.18-0.23점 향상, 문제행동 약 0.005점↓ (all p<.001)

아동 고정효과 모델 (주요 인과 결과):
- 읽기: β=0.018, p>.05 (비유의)
- 수학: β=0.017, p>.05 (비유의)
- 내재화 행동: β=−0.001, p>.05 (비유의)
- 외현화 행동: β=−0.002, p>.05 (비유의)
- 모든 결과 아동 연령별 차이 없음

## Conclusions
아동 고정효과 모델에서 가족 식사 빈도 → 학업·행동 효과 "small or effectively zero"
기존 연구의 긍정적 결과 = 측정되지 않은 혼재 변수 때문
함의: 가족 식사 자체보다 가족 식사를 가능하게 하는 가족 기능·안정성이 핵심
