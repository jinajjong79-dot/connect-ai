Title: Executive Functions and Language Skills in Preschool Children: The Unique Contributions of Working Memory and Cognitive Flexibility
PMC ID: PMC10046801
Year: 2023
Tier: 2 | Grade: A
Category: language_development
Keywords: executive function, language development, working memory, cognitive flexibility, inhibitory control, preschool, Portuguese children, receptive language, expressive language

---

ABSTRACT

This study examined how specific EF components predict language abilities in 79 typically developing Portuguese preschoolers (mean age 64.5 months, 41 girls), controlling for age, gender, and nonverbal intelligence.

Key Findings:
- Working memory → unique 16% of language variance (β=.43, p<.001)
- Cognitive flexibility → unique 19% of language variance (β=.46, p<.001)
- Inhibitory control → NOT significant for language outcomes
- Together WM + CF explain substantial unique language variance beyond IQ

Core message: "작업기억→수용언어, 인지유연성→표현언어. 각각 16%, 19% 분산 설명"

INTRODUCTION

The EF-language connection:
EF and language are closely linked in development:
1. Working memory holds words and sentence structures in mind while processing meaning
2. Cognitive flexibility enables understanding of multiple word meanings, metaphors, context-dependent language
3. Inhibitory control suppresses incorrect word choices in favor of correct ones

Why this matters:
- Language development and EF development peak in the same period (ages 3-7)
- Both rely heavily on PFC
- Bidirectional: EF supports language acquisition; language (especially inner speech) supports EF
- Understanding the unique contributions helps target intervention

METHODS

Design: Cross-sectional
Sample: N=79 Portuguese preschoolers, mean age 64.5 months (~5.4 years), 41 girls
Setting: Portuguese preschools
Development: Typical (no special needs or diagnoses)

EF Measures:
- Inhibitory Control (IC): NEPSY-II Inhibition subtest
  - Motor inhibition: stop/change hand movements on signal
  - Verbal inhibition: say a different color than shown
- Working Memory (WM): Digit Span (forward + backward) from WISC-III
  - Forward: repeat digit sequence
  - Backward: repeat digits in reverse order (more demanding WM)
- Cognitive Flexibility (CF): Semantic Verbal Fluency (BANC)
  - Generate as many words as possible from a category (animals, foods)
  - Switch between categories rapidly
  - Measures both semantic retrieval AND flexible switching

Language Assessment:
- Griffiths Mental Development Scales — Language subscale
- Composite of receptive and expressive language measures

Covariates controlled: age, gender, nonverbal intelligence (Raven's Colored Progressive Matrices)

Statistical analysis: Multiple hierarchical regression
- Step 1: demographics (age, gender)
- Step 2: nonverbal intelligence
- Step 3: EF components (IC, WM, CF) entered separately and together

RESULTS

Working Memory → Language:
- β = 0.43, p < 0.001
- Unique variance explained: 16% (beyond age, gender, IQ)
- Direction: higher WM → better language
- Specific mechanism: holding words, sentence structures, and discourse context in mind while processing

Cognitive Flexibility → Language:
- β = 0.46, p < 0.001
- Unique variance explained: 19% (beyond age, gender, IQ)
- Direction: higher CF → better language
- Specific mechanism: flexible semantic access, understanding multiple meanings, context-switching

Inhibitory Control → Language:
- NOT significant (β = ns)
- IC did not predict language beyond other predictors
- Interpretation: at this developmental stage, IC may have more direct effect on behavior regulation than language processing

Combined model R²:
- WM + CF together explain substantial unique language variance
- This is over and above nonverbal intelligence (IQ)
- Conclusion: EF components are not simply surrogates for intelligence

DISCUSSION

Why WM explains language:
Language comprehension is fundamentally a working memory task:
- Parse sentence → hold beginning while processing end → integrate meaning
- Follow narrative → hold earlier events while processing new ones → build coherence
- Vocabulary learning → hold new word form while associating with meaning → encode

"작업기억이 높을수록 말을 잘 이해한다 — 문장을 머릿속에 붙잡아두는 능력이기 때문"

Why CF explains language (possibly more):
Language production requires accessing the right word from a vast semantic network:
- Semantic fluency is a direct measure of CF applied to language
- CF enables context-appropriate word choice
- Understanding sarcasm, metaphor, humor requires holding one interpretation while entertaining another
- Story comprehension requires shifting perspective between characters

"인지유연성이 높을수록 말을 더 잘 한다 — 상황에 맞게 의미를 전환하는 능력이기 때문"

Why IC did NOT predict language:
IC is primarily about behavioral regulation (stopping actions) rather than semantic processing. At age 5, IC is already relatively developed (EF-221), creating ceiling effects that reduce predictive power for language outcomes.

Practical implications for language intervention:
If a child has language delays, check EF profile:
- WM deficit → language comprehension difficulties → target WM through memory games
- CF deficit → expressive language difficulties → target CF through categorization and switching games
- IC deficit → behavioral issues but not primarily language

Korean context:
- Korean phonology is complex (consonant clusters, honorific register switching)
- CF may be especially important: Korean children must switch between speech registers (반말/존댓말)
- This register-switching is a linguistic CF task
- Children who develop CF earlier may master Korean register distinctions more easily

CONCLUSION

Working memory and cognitive flexibility are significant unique predictors of language development in preschoolers, explaining an additional 16% and 19% of language variance respectively, beyond IQ. Inhibitory control did not independently predict language. This suggests EF-targeted interventions may have secondary benefits for language development, and language-focused interventions should consider WM and CF support.
