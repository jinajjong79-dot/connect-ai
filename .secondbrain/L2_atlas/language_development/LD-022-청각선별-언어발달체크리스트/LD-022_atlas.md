## 연령별 언어발달 체크리스트

**출처**: 대한청각학회 | 신생아 청각선별검사 자료실

---

### 생후 0-3개월
- 큰 소리에 놀라는 반응을 보인다
- 부르면 고개를 움직인다
- 큰 소리에 잠이 깨곤 한다
- 엄마 목소리를 들으면 조용해지곤 한다

### 생후 4-6개월
- '아', '오' 등의 소리를 반복하기 시작한다
- 놀거나 혼자 있을 때 가글하는 것 같은 소리를 낸다
- 일상의 여러 가지 소리(텔레비전, 완구, 악기음 등)에 반응을 보인다

### 생후 7-12개월
- 조용한 환경에서 이름을 부르거나 전화벨 소리, 사람들 소리에 반응한다
- 흔하게 사용하는 단어(맘마, 신발, 안녕 등)에 반응한다
- 옹알이를 한다(다다, 마마, 바바 등)

### 12-18개월
- 반복되는 자음 발음과 더 많은 소리를 모방하여 말할 수 있다
- 이름을 부르면 반응하거나 소리나는 방향을 쳐다본다
- 주변 소음에 귀를 기울인다
- 간단한 지시(우유 먹자)를 이해한다
- '안돼'라는 말을 이해한다

### 18-24개월
- 의미있는 한두 개의 단어를 말하고 흉내낼 수 있다
- 혼자 말하고 소리내면서 놀 수 있다
- 특정 사물을 가리키라고 하면 가리킬 수 있다
- 소리를 이용한 놀이(까꿍, 짝짜꿍)를 좋아한다
- 간단한 지시(공 주세요)를 수행할 수 있다

### 24-30개월
- 반향어와 의미없는 소리들을 내거나 배운 단어들을 사용한다
- 의미 있는 2~3개의 단어를 사용하여 요구한다
- 신체 부위를 1개 이상 가리킬 수 있다
- 간단한 지시를 따라할 수 있다
- 3~10개 이상의 표현 어휘를 습득한다

### 30-36개월
- '엄마', '아빠' 외에 한 단어 이상 말하거나 간단한 표현("우유 줘")을 한다
- 명사와 동사를 결합하기 시작한다
- 단순 예-아니오 식의 질문에 이해하고 반응한다
- "이게 뭐지?"하는 질문에 대답한다
- 동화책을 읽어주거나 이야기 듣는 것을 좋아한다
- 6~20개의 의미있는 단어를 사용한다
- 50~100개 이상의 표현 어휘를 습득한다
- 300개 이상의 수용 어휘를 습득한다

### 3-4세
- 이름과 나이를 말할 수 있다
- 간단한 지시("신발 신어요", "우유 먹어요")를 수행한다
- 두 어절을 이어서("모두 주세요", "책 읽어줘") 말할 수 있다
- 말로 지시한 것을 대부분 이해하고 행동한다
- 배설 욕구를 말로 표현한다
- 3~4 낱말 구를 사용한다
- 모음을 정확하게 사용한다
- 50개 이상의 의미있는 단어를 사용한다
- 50~250개 이상의 표현어휘를 습득한다
- 500~900개 이상의 수용어휘를 습득한다

### 4-5세
- 줄거리가 있는 말을 한다
- 단순한 질문에 대답하고 질문을 하기도 한다
- 속삭여 말하기도 한다
- 언어로 감정을 표현한다
- 4~5 단어 문장을 사용한다
- 또래 아이들만큼 말을 잘 한다
- 800~1500개 이상의 표현어휘를 습득한다
- 1200~2000개 이상의 수용어휘를 습득한다

### 5-6세
- 열까지 세거나 단어의 의미를 묻곤 한다
- 4~8 단어 문장을 사용한다
- 약 90% 정도 자음의 정확도를 가진다
- 두 부분으로 된 복잡한 질문에 대답한다
- 경험을 이야기한다
- 낯선 사람에게도 명료하게 말한다

### 6-7세
- 인사말("안녕")에 적절한 구어로 대답한다
- 요일을 순서대로 말할 수 있다
- 30까지 외워서 셀 수 있다
- 상세한 문장을 사용한다
- 대부분 적절한 문법을 사용한다

### 7세 이상
- 순서대로 수를 셀 수 있다
- 대화에 참여한다
- 약 6개 낱말 정도의 문장 길이를 사용한다
- 대부분의 시간적 개념을 이해한다
