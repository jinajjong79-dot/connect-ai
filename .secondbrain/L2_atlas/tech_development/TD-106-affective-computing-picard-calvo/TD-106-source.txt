=== 감정 컴퓨팅의 정의와 배경 ===

감정 컴퓨팅(Affective Computing)은 MIT 미디어랩의 로잘린드 피카드(Rosalind W. Picard) 교수가 1997년 제안한 개념이다. 정의: "인간의 감정과 관련되거나, 감정에서 발생하거나, 감정에 의도적으로 영향을 미치는 컴퓨팅."

전통적 컴퓨터 시스템은 인간의 감정 상태를 무시했다. 피카드의 핵심 통찰: 감정 없이 지능은 불완전하다. 합리적 의사결정, 학습, 창의성, 사회적 상호작용 모두 감정과 분리할 수 없다.

감정 컴퓨팅의 3대 목표:
1. 감정 인식 (Recognize) — 사용자의 감정 상태를 감지하고 해석
2. 감정 표현 (Express) — 시스템이 감정적으로 적절한 방식으로 반응
3. 감정 영향 (Influence) — 사용자의 감정 상태에 긍정적 영향

=== 피카드의 감정 인식 채널 ===

피카드(1997)가 제시한 감정 인식의 주요 채널:

1. 생리적 신호
   - 피부 전도도 (Galvanic Skin Response, GSR)
   - 심박수 변이 (Heart Rate Variability, HRV)
   - 뇌파 (EEG)
   - 혈압, 호흡 패턴
   → 무의식적 신체 반응을 측정하므로 "속일 수 없는" 데이터

2. 표정 분석 (Facial Action Coding System, FACS)
   - Ekman & Friesen(1978)의 FACS 기반
   - AU(Action Units) 단위로 얼굴 근육 움직임 코딩
   - 기쁨, 슬픔, 분노, 공포, 놀람, 혐오 6개 기본 감정 인식

3. 음성 분석
   - 피치, 강도, 속도, 리듬
   - 분노: 피치↑, 강도↑, 속도↑
   - 슬픔: 피치↓, 속도↓, 음색 탁함

4. 텍스트/언어 분석
   - 단어 선택, 문장 구조
   - 감정 어휘(lexicon) 기반 분류

5. 행동 패턴
   - 마우스 클릭 압력, 키보드 타이핑 속도
   - 자세 변화 (압력 감지 방석 등)

=== 칼보 & 디멜로의 감정 인식 체계 (2010) ===

Calvo & D'Mello(2010)는 기존 연구를 통합하여 감정 인식의 전체 파이프라인을 정리했다.

감정 차원 모델:
- Russell(1980)의 Circumplex Model: 가로축=쾌/불쾌(Valence), 세로축=각성(Arousal)
- 4분면: 기쁨(High V, High A), 불안(Low V, High A), 슬픔(Low V, Low A), 편안(High V, Low A)
- 6개 이산 감정(기본 감정) vs 연속적 차원 모델 비교

기계학습 적용 단계:
1. 데이터 수집 → 레이블링 (자기 보고 또는 전문가 코딩)
2. 특징 추출 (Feature Extraction)
3. 분류 모델 학습 (SVM, Random Forest, Neural Network)
4. 검증 (Cross-validation)

주요 챌린지:
- 감정의 주관성: 같은 자극에 다른 반응
- 문화적 차이: 동아시아 감정 표현 서구 모델 적용의 한계
- 레이블링 어려움: "참 감정" 레이블 획득의 비용

정확도 현황(2010년 기준):
- 표정 인식: 70-90% (통제 환경)
- 음성 인식: 60-80%
- 생리신호: 70-85%
- 멀티모달 융합: 85-95% (복수 채널 결합 시 향상)

=== 아동 감정 인식의 특수성 ===

아동 대상 AI 감정 인식은 성인 모델과 다르다:

1. 발달 단계별 표현 차이
   - 영아(0-12개월): 표정 + 울음이 주요 신호
   - 유아(1-3세): 언어 제한, 몸짓·표정 비중 높음
   - 취학 전(3-6세): 언어로 감정 표현 시작, 아직 조절 미숙
   - 아동(7-12세): 감정 표현 억제 증가 ("울면 안 돼")

2. 아동 FACS의 특수성
   - 성인 FACS로 학습된 모델은 아동에게 전이 어려움
   - 아동 표정은 더 극단적이고 빠르게 변함
   - 아동 전용 데이터셋 필요 (Child Affective Facial Expression, CAFE)

3. 한국 아동 문화 맥락
   - 감정 억제 문화 → 표정 단서 부족
   - 부모 앞 "착한 아이" 행동 → 생리신호 vs 표정 불일치 증가
   - → 멀티모달 접근이 더 중요

=== 양육 도구로서의 AI 감정 인식 ===

감정 인식 AI의 양육 지원 응용:

1. 아이 상태 모니터링
   - "지금 아이가 어떤 상태인지" 객관적 데이터 제공
   - 영아 울음 분류: 배고픔 vs 통증 vs 피곤 (90% 정확도 주장 제품 존재)
   - 피크 감정 시간대 파악 → "하원 후 폭발" 패턴 예측 가능

2. 부모 피드백 시스템
   - 부모의 목소리 톤 분석 → "지금 엄마 목소리가 조금 날카로워요" 피드백
   - 상호작용 패턴 기록 (공감 vs 무시 빈도)

3. 감정 코칭 보조 도구
   - 아이 감정 표현 인식 → 부모에게 "지금 이 감정 이름 알려주세요" 프롬프트
   - Gottman 5단계와 연동 가능: 감정 인식(Step 1)을 AI가 보조

4. 감정 기록 앱
   - 하루 감정 패턴 시각화
   - 부모와 아이 간 감정 동조(co-regulation) 측정

=== 윤리적 고려사항 ===

피카드(1997)와 후속 연구에서 강조한 윤리 원칙:

1. 프라이버시
   - 아동 감정 데이터는 가장 민감한 개인정보
   - 데이터 로컬 처리 원칙 (클라우드 전송 최소화)

2. 동의 (Consent)
   - 아동은 데이터 수집에 동의할 능력이 제한적
   - 부모 동의 + 아동 이해 설명 필수

3. 알고리즘 편향
   - 백인·성인 중심 학습 데이터 → 아시아·아동 적용 시 편향
   - 한국 아동 대상 검증 데이터셋 부재

4. 과의존 위험
   - AI가 부모-아이 상호작용을 중재할 때의 관계 훼손 위험
   - "AI가 맞다"는 맹신 → 부모 직관 약화

5. 감정 조작 가능성
   - 아동 감정 데이터를 마케팅/광고에 활용하는 상업적 남용 위험

=== 현황과 미래 방향 ===

2020년대 감정 컴퓨팅 최신 동향:

1. 대형 언어모델(LLM) + 감정 인식
   - GPT 계열 모델이 텍스트 기반 감정 해석 급진전
   - 멀티모달 LLM (GPT-4V 등): 텍스트+이미지+음성 통합

2. 웨어러블 센서
   - 스마트워치 HRV로 스트레스 실시간 측정
   - 아동용 스마트밴드 → 생리신호 기반 감정 추정

3. 연속 학습 (Continual Learning)
   - 특정 아동의 패턴에 맞춤화되는 개인화 모델
   - "세현이의 울음 = 이 패턴" 학습

4. 한국 연구 동향
   - ETRI, KAIST 등 한국어 감정 코퍼스 구축
   - 한국 아동 음성 감정 데이터셋 부재 → 연구 공백

핵심 메시지 (Picard 요약):
"컴퓨터가 인간을 진정으로 이해하고 지능적으로 상호작용하려면 감정을 인식하고 존중해야 한다. 감정 없는 AI는 진정한 지능이 아니다."

=== 양육 앱 개발 시사점 ===

"세현이와아빠" 채널 + 감정 기록 앱 개발 맥락:

1. 핵심 기능 우선순위
   - 1순위: 텍스트 기반 감정 일기 (LLM으로 분석) — 기술 진입장벽 최소
   - 2순위: 음성 메모 → 자동 감정 분류
   - 3순위: 카메라 표정 분석 (프라이버시 우선 → 온디바이스)

2. 데이터 설계
   - 아이 감정 기록 + 부모 감정 기록을 함께 수집
   - 시간대 패턴 (하원 후, 잠자리 전 등)
   - 트리거 이벤트 태그

3. 피드백 루프
   - 주간 감정 패턴 요약
   - "이 시간대에 자주 폭발하는 패턴이 있어요" 알림
   - 감정코칭 성공 기록 누적
